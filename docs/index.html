Firmware Installer

Install eData on your Xteink X3/X4

Plug the device into this computer with a USB cable and press Install. Your browser does the rest — nothing to download, nothing to set up.

New project — verified on X3, X4 still pending

eData is new, but this build is confirmed working on a real Xteink X3 - all three box counts (1, 2, and 4 boxes per screen) tested and working. An X4 is on order; until it arrives, this installer only offers the X3 image. It shares its network/settings/ power code with eNMEA, which has been hardware-tested extensively - so that part of the behavior (Wi-Fi setup, source profiles, power button, going back to the e-reader) works the same way here. See the repository for what's still open.

This page was opened from a file on disk, so it cannot install anything. A local page has no web origin, so the browser blocks it from reading the firmware manifest — you would get a CORS error rather than a useful message. Open cffinch62.github.io/eData instead.
This browser can't flash devices. Use Chrome or Edge on a desktop or laptop — they support Web Serial, which is how the page talks to the device. Safari, Firefox, and phone browsers can't.
This page needs to be served over HTTPS to talk to a USB device.

What happens

  1. Connect the device to this computer with a USB-C data cable. Some cables are charge-only and won't work — if the device never appears, that's the first thing to swap.
  2. Press Install, then pick the device from the list your browser shows. It will be named something like USB JTAG/serial debug unit.
  3. Wait about a minute. The page erases the old firmware and writes the new one. Don't unplug during this.
  4. The screen shows SETUP MODE when it's done, and the device starts its own Wi-Fi network called eData-Setup.
  5. Join that network from your phone and open http://192.168.7.1/ to enter your Wi-Fi details, your NMEA source, and the display layout - how many boxes per screen (1, 2 or 4) and which of the 13 nav items go in each of the 8 configurable slots. You can store up to eight source profiles and switch between them later with the device's own buttons. The README walks through it.

Before you start

What you needChrome or Edge, on a computer. Windows, Mac or Linux. Safari and Firefox cannot do this, and neither can any phone or tablet — the technology the page uses to talk to USB devices does not exist on them.
The cable mattersIt must be a USB-C data cable. Many cables that came with chargers carry power only, and the device will simply never appear. This is the single most common reason an install won't start.
Which devicesThis page installs the Xteink X3 build. If you need the X4/X4 Pro build instead, see the repository for building and flashing it directly with PlatformIO - only the X3 build is offered as a one-click browser install here.
How longAbout a minute. Don't unplug while it's working.

Will I lose anything?

Your books and filesNo. Everything on the SD card is untouched. Installing only rewrites the chip's internal memory, and eData never reads or writes the card at all.
The e-reader softwareReplaced — but you can put it back whenever you like. See Going back to the e-reader.
eData's own settingsYes. Every install clears the saved Wi-Fi, NMEA source and display-layout settings, so the device always starts fresh in SETUP MODE. That is expected, including when updating to a newer version.

Do I need to tick "Erase device"?

No — leave it unticked. The install already replaces everything eData uses, and it is quicker this way.

Ticking it does no harm. It additionally clears leftover e-reader data sitting in areas eData never looks at. The only downsides are that a full erase takes noticeably longer, and if something interrupts it you are left with a completely empty device rather than a half-written one — both fixed by simply installing again.

Either way your Wi-Fi and display settings are cleared, so expect SETUP MODE on the first start.

It won't install

No device appears when I press InstallIn order of likelihood: the cable is charge-only — try a different one; another browser tab or program is already using the device — close any other flashing page, serial monitor or Arduino window and try again; the USB port is faulty — try another.
Which one do I pick from the list?It appears as something like USB JTAG/serial debug unit. If several entries look similar, unplug the device, see which one disappears, and plug it back in.
"Failed to download manifest"You opened this page from a file saved on your computer instead of from the web. Go to cffinch62.github.io/eData and try again.
"Partition table is missing an OTA app slot"That message comes from the e-reader's installer, not this one. eData ships the same dual-OTA partition table as eNMEA/eAIS from its first build, so this shouldn't come up - if it does, it means the .bin you installed predates the partition table in the current source. Reinstall from the button above.
It stopped partway throughUnplug, plug back in, and press Install again. A half-finished install cannot damage the device; the next one rewrites everything from the beginning.
Nothing works, on LinuxYour account needs permission to use serial devices. In a terminal: sudo usermod -aG dialout $USER — then log out and back in for it to take effect.

It installed — now what?

The screen shows SETUP MODE and the device starts its own Wi-Fi network. Join eData-Setup from your phone, open http://192.168.7.1/, and fill in the form - Wi-Fi, NMEA source, and the display layout. The README covers the instrument display in full.

It won't join my Wi-FiThe device is 2.4 GHz only — it has no 5 GHz radio. If your network is 5 GHz-only, or your router steers devices to 5 GHz under the same network name, it cannot connect. Check the password too. After 15 seconds of failing it returns to SETUP MODE by itself, so you are never locked out.
A box says NO DATA AVAILABLEThat data item's sentence hasn't arrived yet - either your source doesn't send it, or (for Distance/Bearing/XTE/ETA/Time-To-Go) there's no active route on the source, or boat speed is too low for a meaningful ETA. Look at the word after SOURCE: in the footer: LISTENING means you chose UDP but your equipment expects TCP; FAILED means it cannot reach the address you entered; NO DATA means the connection is fine and your equipment stopped sending.
How do I change what's on screen?Use LEFT/RIGHT on the device to scroll between configured pages. To change box count or which items are shown, go back to the setup page (eData-Setup or the device's own IP) - saving a new layout there takes effect within a couple of seconds, no reboot needed.
It worked at home but not on the boatIf you use TCP, the Host address belongs to a particular network. Move the device somewhere else and that address is usually wrong. Re-enter it from the setup page.
How do I get back to the settings?Join eData-Setup and open 192.168.7.1 — that network stays available the whole time the device is on, even while it is connected to your Wi-Fi. Or hold the BACK button for 3 seconds to forget the Wi-Fi/source settings currently in use and fall back to any others you have stored.
How do I turn it off?Hold the power button for 2 seconds. Press it once to turn back on.
It still shows a picture when it's offNormal. This kind of screen keeps its last image with no power at all — it is not still running.
The screen is blank or stuckHold power for 2 seconds to switch off, then press power to start again. If it stays blank, install once more from this page.

Going back to the e-reader

eData ships the same partition table as eNMEA/eAIS specifically so it stays compatible with CrossInk's own installer - this hasn't been run through the full round trip on eData itself yet the way eNMEA's was, but the mechanism is identical. CrossInk, the e-reader firmware these devices usually run, has its own one-click web installer:

inky.crossink.dev — pick your device model and press flash, exactly like this page.

Two things worth knowing before you switch either direction:

Your books are safeEverything on the SD card is untouched. Flashing only rewrites the chip's internal memory; eData never reads or writes the card at all.
Settings do not surviveInstalling anything resets the saved Wi-Fi, source and display settings, in both directions. Expect to set the device up again after a switch — a minute's work, not a problem.

We deliberately don't host CrossInk builds here. Getting them from the project itself means you get the current, official firmware for your exact model rather than a copy that quietly falls behind.

Prefer the command line?

The same image flashes with esptool, no browser involved:

esptool --chip esp32c3 write-flash 0x0 eData-x3-<version>.bin

Grab the .bin from the firmware folder. Building from source is in the repository README.
